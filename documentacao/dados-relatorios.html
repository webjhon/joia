Dados, sessões e relatórios

O que fica no navegador, na sessão PHP e nos arquivos de memória da JOIA.

Três níveis de estado

NavegadorsessionStorage: ID da conversa. localStorage: caderno pessoal.
Sessão PHPEtapa do cadastro, vínculo com aluno, estado docente e PDF temporário.
DiscoPerfil e histórico em memoria/aluno_*.json.

Formato da memória

Cada cadastro recebe 16 bytes aleatórios convertidos em 32 caracteres hexadecimais. O nome do arquivo deriva desse ID validado, nunca do nome do aluno.

JSON ilustrativo
{
  "schema_version": 2,
  "id": "32-caracteres-hexadecimais",
  "profile": {
    "full_name": "Pessoa Exemplo",
    "preferred_name": "Pessoa",
    "class": "Turma A",
    "institution": "Escola Exemplo"
  },
  "created_at": "data UTC",
  "updated_at": "data UTC",
  "history": []
}

Cada interação adiciona dois itens ao histórico com o mesmo timestamp UTC: um de papel user e outro assistant.

Listagem e seleção docente

allStudents() percorre arquivos válidos, exige ID e nome, ordena alfabeticamente e calcula interações dividindo o número de itens por dois. studentTable() cria uma tabela Markdown e remove barras verticais dos dados. findStudent() aceita número exato ou parte inequívoca do nome normalizado.

Ordenação
usort($students, static function (array $a, array $b): int {
  return strcasecmp(
    $a['profile']['full_name'],
    $b['profile']['full_name']
  );
});
Seleção por nome
$matches = array_values(array_filter($students,
  static fn(array $student): bool =>
    $needle !== '' && strpos(
      normalize($student['profile']['full_name']), $needle
    ) !== false
));
return count($matches) === 1 ? $matches[0] : null;

Preparação do texto para PDF

pdfText() converte UTF-8 para Windows-1252, compatível com as fontes nativas usadas. pdfEscape() protege barra, parênteses e retorno de carro. pdfWrap() quebra palavras conforme o limite de cada tipo de bloco.

Codificação e escape
function pdfEscape(string $text): string
{
  return str_replace(
    ['\', '(', ')', "
"],
    ['\\', '\(', '\)', ''],
    pdfText($text)
  );
}

Interpretação e paginação

pdfBlocks() normaliza quebras, reconhece os títulos esperados mesmo se vierem na mesma linha e classifica cada trecho como título, item ou parágrafo. buildPdf() calcula a altura, abre nova página após 630 pontos úteis e desenha cabeçalho, conteúdo e rodapé.

Limites visuais
$limit = $type === 'heading' ? 64
  : ($type === 'bullet' ? 88 : 94);
$height = $type === 'heading' ? 18 : 14;
if ($used > 0 && $used + $needed > 630) {
  $page++;
  $pages[$page] = [];
  $used = 0;
}

$objects[3] = '<< /Type /Font /Subtype /Type1 '
  . '/BaseFont /Helvetica /Encoding /WinAnsiEncoding >>';
$objects[4] = '<< /Type /Font /Subtype /Type1 '
  . '/BaseFont /Helvetica-Bold /Encoding /WinAnsiEncoding >>';

Entrega do documento

Após a solicitação, o servidor cria uma chave aleatória, guarda o relatório na sessão e retorna uma URL. O GET seguinte só funciona na mesma sessão e enquanto esse dado existir.

Criação do download
$key = bin2hex(random_bytes(16));
$_SESSION['reports'][$key] = [
  'text' => $state['report_text']
];
respond([
  'resposta' => 'O relatório foi diagramado.',
  'download' => 'teste_openai.php?pdf=' . $key
]);
