Glossário

API
Contrato de comunicação entre navegador e servidor.
Contexto
Mensagens e instruções enviadas ao modelo.
JSON
Formato textual estruturado usado na API e memória.
Prompt
Instrução enviada ao modelo.
Sessão
Estado temporário conservado pelo PHP para aquele navegador.
Token
Unidade de texto processada pelo modelo; em segurança, também pode significar credencial.
