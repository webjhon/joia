MODELO E PEDAGOGIA

Inteligência artificial

Como a JOIA constrói contexto, consulta o modelo e mantém sua proposta educacional.

Modelo utilizado

gpt-4o-minimodelo configurado
0,35temperatura padrão
900tokens padrão de saída
12itens recentes de histórico

A integração usa Chat Completions. Relatórios aumentam o limite de saída; o cadastro usa respostas menores. O modelo não acessa diretamente arquivos, sessões ou memórias: somente recebe as mensagens preparadas pelo PHP.

Camadas de contexto

  1. Documentos pedagógicostreinamento.txt e NEGATIVEPROMPTS.TXT.
  2. Regra do sistemaIdioma, identidade e proteção das instruções.
  3. Perfil confirmadoDados do cadastro para personalizar sem repeti-lo.
  4. Histórico recenteAté 12 itens, preservando papéis de usuário e assistente.
  5. Mensagem atualA solicitação que deve ser respondida.
Ordem das mensagens

Treinamento e restrições

O treinamento descreve a JOIA como guia: investigar o que o aluno entende, oferecer pistas graduais, variar a abordagem e incentivar reflexão. As restrições complementares impedem comportamentos que contradizem essa proposta.

Conteúdo protegido: esta referência explica a função dos arquivos, mas não publica suas instruções integrais. Revelá-las facilitaria contornar os controles pedagógicos.

Revisão pedagógica automática

A resposta não vai diretamente ao navegador. O servidor identifica blocos cercados por crases e linhas com palavras/padrões típicos de programação. Mais de duas linhas, ou novo código logo após código recente, acionam uma segunda consulta sem código.

Contagem de blocos
if (preg_match_all('/```[^
]*
(.*?)```/s', $answer, $blocks)) {
  foreach ($blocks[1] as $block) {
    foreach (preg_split('/\R/', trim($block)) as $line) {
      if (trim($line) !== '') $count++;
    }
  }
}

A contagem é uma heurística, não um parser de linguagens. Ela prioriza o objetivo educacional e possui uma resposta local de último recurso caso o modelo desobedeça também na repetição.

Cadastro assistido por IA

O PHP decide se um valor é aceitável; a IA apenas formula a pergunta natural da etapa. Isso separa regra de negócio de estilo conversacional. Saudações, perguntas ou frases muito longas não são aceitas como nome.

Etapas
welcome → nome completo
name    → turma, curso, ano ou período
class   → instituição, escola ou unidade
conversation → conversa educacional

Relatório educacional

O modelo recebe perfil e conversas e redige seções fixas: identificação, síntese, conhecimentos, lacunas, estratégias, recomendações e próximos passos. A instrução exige diferenciar evidência de inferência e proíbe diagnóstico médico.

Entrada do relatório
$messages[] = [
