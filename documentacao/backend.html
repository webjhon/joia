Inicialização e contrato HTTP

O arquivo usa tipagem estrita, oculta erros da resposta pública e registra falhas fatais. O manipulador de exceções devolve JSON genérico; detalhes são enviados somente ao log do PHP.

Resposta centralizada
function respond(array $payload, int $status = 200): void
{
    http_response_code($status);
    echo json_encode($payload,
        JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES);
    exit;
}

Normalização e memória

normalize() aplica trim, minúsculas, transliteração ASCII e troca pontuação por espaços. Isso permite reconhecer intenções sem depender de acentos.

Normalização
function normalize(string $value): string
{
    $value = mb_strtolower(trim($value), 'UTF-8');
    $ascii = iconv('UTF-8', 'ASCII//TRANSLIT//IGNORE', $value);
    return trim(preg_replace('/[^a-z0-9]+/', ' ', $ascii) ?? '');
}

memoryDirectory() localiza/cria memoria; memoryPath() aceita somente ID hexadecimal de 32 posições; loadMemory() decodifica JSON; saveMemory() atualiza a data e grava com LOCK_EX.

Gravação
function saveMemory(array $memory): void
{
    $memory['updated_at'] = gmdate('c');
    $json = json_encode($memory,
        JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
    file_put_contents(memoryPath($memory['id']), $json, LOCK_EX);
}

Chamada à OpenAI

callOpenAI() valida cURL, coloca os documentos na primeira posição, configura corpo, timeouts e cabeçalhos, executa a requisição, verifica HTTP e extrai a resposta. Em modo estruturado, adiciona response_format: json_object.

  'max_tokens' => $maxTokens

Configuração cURL

Limite pedagógico de código

codeLineCount() conta linhas em blocos Markdown e padrões comuns fora deles. recentCodeWasGiven() examina as últimas 12 mensagens; isExplicitCodeRequest() reconhece pedidos; consecutiveCodeRequests() mede insistência.

Decisão principal
function enforcePedagogicalCodeLimit(
  string $answer, array $history,
  string $message, array $messages
): string {
  $codeLines = codeLineCount($answer);
  if ($codeLines <= 2 &&
      ($codeLines === 0 || !recentCodeWasGiven($history))) {
      return $answer;
  }
  return pedagogicalRetry($messages, $message,
      consecutiveCodeRequests($message, $history));
}

pedagogicalRetry() solicita uma resposta conceitual sem código. Se a segunda tentativa ainda falhar, o sistema remove blocos ou usa uma pergunta pedagógica local.

conversation() mantém na sessão um estado com stage, draft e estado docente. onboardingValue() limpa e limita a entrada; onboardingReply() conduz nome, turma/curso e instituição, uma etapa por vez.

Roteamento da requisição

GET com uma referência temporária entrega PDF. Outros GETs recebem 405. No POST, o PHP lê JSON, higieniza conversation_id, trata reset e valida mensagem. Depois percorre: área docente protegida, cadastro inicial ou conversa normal.

$conversationId = preg_replace('/[^a-zA-Z0-9-]/', '',
  (string) ($input['conversation_id'] ?? ''));
if ($conversationId === '' || strlen($conversationId) > 80) {
  respond(['erro' => 'Conversa inválida.'], 422);
